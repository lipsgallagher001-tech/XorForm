## 🚀 Démarrage Rapide (30 minutes)

### 1. Générer les favicons (5 min)
```bash
npm install sharp
npm run generate-favicons
```

### 2. Créer les images Open Graph (15 min)
Utiliser [Canva](https://www.canva.com) ou Figma pour créer:
- `og-image.png` (1200x630px)
- `twitter-image.png` (1200x675px)
- `screenshot.png` (1280x720px)

📖 **Guide complet:** `create-og-images.md`

### 3. Intégrer le composant SEO (2 min)
Dans `src/App.tsx`:
```tsx
import SEO from './components/SEO';

// Au début du return:
<SEO 
  title="XorForm - Générateur de Proforma et Factures"
  description="Créez des proformas et factures professionnels"
/>
```

### 4. Tester et déployer (8 min)
```bash
npm run build
npm run preview
# Puis déployer sur Vercel/Netlify
```
